# CommandManager.clearAiChat

```kotlin
fun clearAiChat()
```

## 概要

AI チャットの表示を消して先頭に戻す。FEATURE_VERSION 1.1.0 以降のファームが対象で、未対応のファームはこのコマンドを読み捨てるため表示が残る。

## 戻り値

`Unit`
