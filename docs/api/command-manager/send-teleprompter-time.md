# CommandManager.sendTeleprompterTime

```kotlin
fun sendTeleprompterTime(time: String)
```

## 概要

再生開始からの経過時間を送る。

## 引数

| 名前 | 型 | 説明 |
|---|---|---|
| `time` | `String` | `mm:ss` 形式の5文字。短ければ先頭を0埋め、長ければ切り捨てる |

## 戻り値

`Unit`
