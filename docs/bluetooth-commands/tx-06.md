# 0x06 設定変更・同期要求

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `06` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | キーの長さ | UTF-8の設定キー |
| `02` | `02 00` | 整数（2 byte、LE） |
| `03` | `02 00` | false `00 00` / true `01 00` |
| `04` | 文字列の長さ | UTF-8文字列 |
| `05` | データの長さ | バイト列 |
| `80` | `02 00` | 同期要求 `00 00` |

設定変更はキー `01` → 値 `02` / `03` / `04` / `05` の2つのTLVを送る。
設定キーには `FONT_SIZE`、`BRIGHTNESS_LEVEL`、`SCREEN_OFF_TIME` などを指定する。
同期要求は `80` のTLV単独で送る。設定値は受信コマンド `0x83` で返る。

同期要求のパケット：

```text
01 06 80 05 00 80 02 00 00 00
```
