# 0x04 テレプロンプター

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `04` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | 2 + 本文の長さ | 分割マーカー（2 byte）→ UTF-8本文 |
| `02` | `02 00` | 上へ1行 `01 00` / 下へ1行 `02 00` |
| `03` | `02 00` | 進捗率（1 byte、0〜100）→ `00` |
| `04` | `02 00` | 生成中 `00 00` |
| `05` | `02 00` | 準備 `00 00` / 再生 `01 00` / 一時停止 `02 00` |
| `06` | `05 00` | `mm:ss` のUTF-8文字列 |
| `07` | `02 00` | テレプロンプター `00 00` / 文字起こし `01 00` / 翻訳 `02 00` |

画面ID `0x0033` を開いてから送る。

| 操作 | 内側TLVの並び |
|---|---|
| 本文全体の更新 | 進捗 `03` → 本文 `01` |
| 1行更新 | 行移動 `02` → 進捗 `03` → 本文 `01` |
| 状態・モード変更 | 状態 `05` → モード `07` |
| 時間更新 | 時間 `06` |

本文は1パケット200 byteまで。分割時は先頭に進捗と本文、以降に本文のTLVを送る。
1行更新の本文には `5A 6B` を付ける。
