# CommandManager.sendSettingPageVisibility

```kotlin
fun sendSettingPageVisibility(show: Boolean)
```

## 概要

## 引数

| 名前 | 型 | 説明 |
|---|---|---|
| `show` | `Boolean` | `true` で表示、`false` で非表示 |
