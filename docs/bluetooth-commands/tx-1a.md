# 0x1A 分割レイアウト

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `1A` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | `02 00` | モード（2 byte、LE） |
| `02` | 1 + 本文の長さ | 領域番号（1 byte）→ UTF-8本文 |

モード `01` → 領域テキスト `02` の順に連結する。複数の領域は `02` のTLVを繰り返す。
ペイロードの合計は190 byteまで。送信するとレイアウト画面に切り替わる。
モードを送ると全領域をクリアし、同じパケットの本文を表示する。
モードを省略すると指定した領域だけを更新する。本文を空にするとその領域を消す。

| モード値 | 配置 | 領域番号 |
|---|---|---|
| `00 00` | 閉じる | — |
| `01 00` | 全画面 | 0 |
| `02 00` | 上下 | 0：上、1：下 |
| `03 00` | 左右 | 0：左、1：右 |
| `04 00` | 4分割 | 0：左上、1：右上、2：左下、3：右下 |
