# 0x10 ナビゲーション

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `10` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | `02 00` | 準備 `00 00` / 開始 `01 00` / 到着 `02 00` |
| `02` | `02 00` | 進行方向アイコン（1 byte）→ `00` |
| `03` | 文字列の長さ | 案内文（UTF-8） |
| `04` | 文字列の長さ | 次の地点までの距離（UTF-8） |
| `05` | 文字列の長さ | 到着予定時刻（UTF-8） |
| `06` | 文字列の長さ | 残り時間・距離（UTF-8） |
| `07` | `02 00` | 小画像の幅（1 byte）→ `00` |
| `08` | `02 00` | 小画像の高さ（1 byte）→ `00` |
| `09` | 2 + 圧縮データの長さ | 分割マーカー（2 byte）→ 小画像の圧縮データ |
| `0A` | `02 00` | 大画像の幅（2 byte、LE） |
| `0B` | `02 00` | 大画像の高さ（2 byte、LE） |
| `0C` | 2 + 圧縮データの長さ | 分割マーカー（2 byte）→ 大画像の圧縮データ |
| `0D` | `02 00` | 進行方位×10（2 byte、LE、0〜3599） |
| `0E` | 言語コードの長さ | `JPN` / `ENG` など（UTF-8） |

画面ID `0x0043` を開いてから送る。進行方位は北が0度、時計回り。
状態・進行方位・言語はそれぞれ単独のTLVで送る。

案内の更新は `02` → `03` → `04` → `05` → `06` のTLVを連結する。
小画像付きの先頭パケットには続けて `07` → `08` → `09` を載せる。
大画像の先頭パケットは `0A` → `0B` → `0C`。
画像の圧縮は[3bit RLE](tx-1b.md#image-rle)を使い、圧縮データを先頭64 byte、以降200 byteまでに分割する。
続きのパケットには画像データのTLVだけを載せる。
マーカーは先頭 `5A 5A`、途中 `7C 7C`、末尾 `6B 6B`。1パケットの場合は `5A 5A`。

| アイコン値 | 意味 | アイコン値 | 意味 |
|---|---|---|---|
| `00` | UNKNOWN | `08` | TURN_LEFT |
| `01` | FORK_LEFT | `09` | TURN_RIGHT |
| `02` | FORK_RIGHT | `0A` | TURN_SHARP_LEFT |
| `03` | RAMP_LEFT | `0B` | TURN_SHARP_RIGHT |
| `04` | RAMP_RIGHT | `0C` | TURN_SLIGHT_LEFT |
| `05` | ROUNDABOUT_LEFT | `0D` | TURN_SLIGHT_RIGHT |
| `06` | ROUNDABOUT_RIGHT | `0E` | U_TURN_LEFT |
| `07` | STRAIGHT | `0F` | U_TURN_RIGHT |
