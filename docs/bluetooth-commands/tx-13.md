# 0x13 汎用画像

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `13` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | `02 00` | 幅（2 byte、LE） |
| `02` | `02 00` | 高さ（2 byte、LE） |
| `03` | 2 + 圧縮データの長さ | 分割マーカー（2 byte）→ 圧縮データ |

画面ID `0x0046` を開いてから送る。幅・高さは各1〜196。
画像の圧縮は[3bit RLE](tx-1b.md#image-rle)を使う。
圧縮データを先頭64 byte、以降200 byteまでに分割する。
先頭パケットは幅 `01` → 高さ `02` → 画像 `03`、続きは画像 `03` のTLVを送る。
マーカーは先頭 `5A 5A`、途中 `7C 7C`、末尾 `6B 6B`。1パケットの場合は `5A 5A`。
