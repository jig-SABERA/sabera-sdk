# 0x16 汎用テキスト

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `16` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | 2 + 本文の長さ | 分割マーカー（2 byte）→ UTF-8本文 |
| `02` | `02 00` | 準備 `00 00` / 再生 `01 00` / 一時停止 `02 00` |

画面ID `0x0047` を開いてから本文 `01` を送る。
本文は1パケット200 byteまで。文字境界で分割し、各パケットに本文TLVを載せる。
1パケットは `5A 6B`、分割時は先頭 `5A 5A`、途中 `7C 7C`、末尾 `6B 6B`。
