# CommandManager.sendNaviLanguage

```kotlin
fun sendNaviLanguage(languageCode: String)
```

## 概要

ナビ画面の表示言語を通知する。到着時刻のラベル等の切り替えに使われる。

{: .note }
> 0.0.10 には含まれない。次のリリースから使える。

## 引数

| 名前 | 型 | 説明 |
|---|---|---|
| `languageCode` | `String` | `"JPN"` / `"ENG"` 等の3文字 |

## 戻り値

`Unit`
