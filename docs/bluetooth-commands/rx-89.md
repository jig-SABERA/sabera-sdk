# 0x89 IMUデータ

コマンド受信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `89` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | `14 00` | タイムスタンプ → 加速度X/Y/Z → 角速度X/Y/Z → pitch → yaw |

| タイムスタンプ | 加速度X/Y/Z | 角速度X/Y/Z | pitch | yaw |
|---|---|---|---|---|
| 4 byte | 各2 byte、計6 byte | 各2 byte、計6 byte | 2 byte | 2 byte |

Valueは20 byte、外側Lengthは `17 00`、パケット全体は28 byte。
すべてLE。タイムスタンプは起動からのミリ秒を符号なし32 bitで表す。
加速度は符号付き16 bit、単位はmilli-g。
角速度は符号付き16 bit、単位は0.1度/秒。
pitch・yawは符号付き16 bit、単位は0.1度。`imuData` で購読できる。
