# 0x12 AIチャット

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `12` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | 本文の長さ | UTF-8本文 |
| `02` | `01 00` | AI `00` / ユーザー `01` |
| `03` | `01 00` | 生成中 `00` / 完了 `01` |
| `04` | `01 00` | SABERA AI `00` / Gemini `01` |
| `05` | 言語コードの長さ | `JPN` / `ENG` / `CHS` / `CHT` など（UTF-8） |
| `06` | `01 00` | クリア `01` |

画面ID `0x0045` を開いてから送る。本文のValueはUTF-8文字列。

| 操作 | 内側TLVの並び |
|---|---|
| 本文を送る | 本文 `01` |
| 送信者を指定して本文を送る | 送信者 `02` → モデル `04`（AIの場合）→ 本文 `01` |
| 状態を送る | 状態 `03` |
| 送信者を指定して状態を送る | 送信者 `02` → モデル `04`（AIの場合）→ 状態 `03` |
| 言語を設定する | 言語 `05` |
| 表示をクリアする | クリア `06` |

`clearAiChatLegacy()` は本文 `01` に改行 `0A` を10個入れて送る。
