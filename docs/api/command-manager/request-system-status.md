# CommandManager.requestSystemStatus

```kotlin
fun requestSystemStatus()
```

## 概要

バッテリー残量・装着状態・充電状態の通知をグラスに要求する。充電状態は charging に反映される。残量と装着状態は parseResponse で受ける。

## 戻り値

`Unit`
