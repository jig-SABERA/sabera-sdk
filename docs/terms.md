# SABERA App SDK 利用規約

本SDK 利用規約（以下「本規約」といいます）は、株式会社jig.jp（以下「当社」といいます）が
開発者向けに無償で提供するソフトウェア開発キット「SABERA App SDK」（以下「本SDK」といいます）
の利用条件を定めるものです。

第一版: 2026年9月1日

## 第1条（適用）

1. 本規約は、本SDK の利用に関する当社と開発者との間の一切の関係に適用されます。
2. 開発者は、本SDK が提供する同意手続を完了することによって、本規約に同意したものとします。当該手続を経ずに本SDK の全部または一部を利用した場合も、開発者は本規約に同意したものとみなします。
3. 法人または団体を代表して本SDK を利用する場合、開発者はその法人または団体を本規約に拘束する権限を有することを表明するものとします。
4. 本規約は第2条に定める本SDK にのみ適用されます。当社が別途ライセンスを表示して公開するサンプルコード等には、本規約ではなく当該ライセンスが適用されます。

## 第2条（定義）

| 用語 | 意味 |
|---|---|
| 本SDK | `jp.jig.sabera.app.sdk` を名前空間とする Android 向けライブラリ（AAR）、iOS 向けフレームワーク（XCFramework）およびこれらに付随するドキュメント |
| 本デバイス | 当社または当社の指定する事業者が販売する AR グラス「SABERA」およびその後継機 |
| 開発者 | 本SDK を利用する個人または法人 |
| 開発者アプリ | 開発者が本SDK を組み込んで開発するアプリケーション（当社が提供するアプリケーションを含みません） |
| 利用者 | 開発者アプリを利用する者 |

## 第3条（ライセンスの付与）

1. 当社は開発者に対し、本規約の遵守を条件として、次の行為を行う非独占的、譲渡不能、サブライセンス不可、地域の限定のない無償の権利を許諾します。
   - 本デバイスと連携する開発者アプリを開発、検証する目的で本SDK を複製し、利用すること
   - 本SDK を開発者アプリに組み込んだ形態で、開発者アプリを第三者に配布すること
2. 本条の許諾は商用利用を含みます。当社は本SDK の利用に対して対価を請求しません。
3. 本規約に明示的に定めのない権利は、すべて当社に留保されます。

## 第4条（禁止事項）

開発者は次の行為を行ってはなりません。

1. 本SDK を開発者アプリに組み込まない形態で、単体または他のライブラリの一部として再配布、貸与またはサブライセンスすること
2. 本SDK に含まれる著作権表示、商標表示その他の権利表示を削除または改変すること
3. 本SDK の通信仕様を解析し、本SDK を経由せずに本デバイスを制御する実装を作成または配布すること
4. 本デバイスのファームウェアを解析、改変または書き換えること
5. 開発者アプリを通じて、法令もしくは公序良俗に反する内容、または装着者の安全な行動を妨げる態様の表示を本デバイスに表示させること
6. 法令、公序良俗または本規約に違反する行為

## 第5条（表示義務）

1. 開発者は、開発者アプリを配布するにあたり、本SDK に含まれる第三者ソフトウェアについて、サードパーティ表記に定める著作権表示および免責文を利用者が閲覧できる形で表示しなければなりません。
2. 「SABERA」「SABERA App SDK」その他の当社の名称、商標およびロゴの使用は、開発者アプリが本デバイスに対応することを事実として示す範囲に限られます。当社または当社製品による推奨、提携または保証を示唆する表示は、当社の書面による事前の同意を必要とします。
