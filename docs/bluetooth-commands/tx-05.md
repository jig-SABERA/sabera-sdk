# 0x05 画面遷移

コマンド送信。

| ヘッダ | コマンドID | Type | Length | Value |
|---|---|---|---|---|
| `01` | `05` | `80` | LE(ペイロード長) | 内側TLV |
| 1 byte | 1 byte | 1 byte | 2 byte | 可変長 |

`LE(n)` は整数nを2 byteのリトルエンディアンで表した値。Nは本文または圧縮データのbyte数。
[共通のパケット形式](../bluetooth-commands.md#通常パケットの形式)を参照。

画面を開いてからコンテンツを送信する。

| Type（1 byte） | Length（2 byte、LE） | Value |
|---|---|---|
| `01` | `02 00` | 画面ID（2 byte、LE） |

| 画面ID | 画面 | 対応API |
|---|---|---|
| `0x0032` | ホーム | `enterHomePage()` |
| `0x0033` | テレプロンプター | `enterTeleprompterPage()` |
| `0x003A` | 翻訳 | `enterTranslatePage()` |
| `0x0043` | ナビゲーション | `enterNavigationPage()` |
| `0x0045` | AIチャット | `enterAiChatPage()` |
| `0x0046` | 汎用画像 | `enterImageDisplayPage()` |
| `0x0047` | 汎用テキスト | `enterEmptyScreenPage()` |
| `0x0072` | ヘッドアップ角度調整 | `enterGlassAngleAdjustmentPage()` |
| `0x0073` | IMU・照度デバッグ | `enterImuDebugPage()` |
